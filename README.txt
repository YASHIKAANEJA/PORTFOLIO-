YASHIKA ANEJA — ANIMATED DATA ANALYST PORTFOLIO

Files:
- index.html       Home
- projects.html    Projects + filters
- about.html       About + skills
- experience.html  Journey / education / experience
- contact.html     Contact
- style.css        Dark animated visual system
- main.js          Navigation, reveal animation, cursor, filters
- assets/          Uploaded pixel-art image + video

HOW TO RUN
1. Open index.html directly, or use VS Code Live Server.
2. Replace the placeholder email and social URLs in contact.html.
3. Replace project visuals in assets/ with your real dashboard screenshots when ready.
4. Deploy the folder to GitHub Pages, Netlify or Vercel.

DESIGN DIRECTION
Dark editorial portfolio, lime accent, glass navigation, grid background, reveal animations,
marquee, hover interactions, floating pixel-art analyst character and multi-page structure.
Inspired by the provided reference site, but reworked around a data analyst identity.
